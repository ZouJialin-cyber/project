# project_bgi_img_proc文件夹是之前处理图像数据的代码
# opencv文件夹是学习opencv的代码
# 这里只记录opencv文件夹中程序的功能

图像的几何变换1.py：基本的图像变换代码，包括仿射变换如：平移、缩放、旋转和翻转

图像的几何变换2.py：高阶的图像变换代码，包括斜切、投影（图像校正）和重映射（实现基本的仿射变换，也可以通过重映射实现动态图像）

图像的灰度变换.py：图像的反色处理（直接用数学方法255-img，和LUT查表计算方法），直方图正规化cv.normalize的使用

图像的直方图处理.py：灰度图与彩色图的直方图展示，灰度图的直方图均衡化（全局），灰度图的限制对比度自适应局部直方图均衡化

图像的阈值处理.py：
固定阈值法，使用固定阈值对灰度图进行前景背景分类；全局阈值法，找到一个适合全局灰度值的固定阈值，对前景背景分类；OSTU阈值算法，使用最大化类间方差找到一个最优阈值T，进行阈值分割；多阈值处理会基于OSTU算法找到多个类间方差进行阈值分割；自适应阈值处理是局部阈值处理，基于像素邻域的内容平均值或高斯加权计算邻域的阈值，抗干扰性强；移动平均阈值处理，和自适应阈值相比，只使用固定的邻域大小和平均值计算邻域阈值，抗干扰能力弱，但是可以基于Numpy数组运算，速度快
