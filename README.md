# project_bgi_img_proc文件夹是之前处理图像数据的代码
# opencv文件夹是学习opencv的代码
# 这里只记录opencv文件夹中程序的功能

图像的几何变换1.py：基本的图像变换代码，包括仿射变换如：平移、缩放、旋转和翻转

图像的几何变换2.py：高阶的图像变换代码，包括斜切、投影（图像校正）和重映射（实现基本的仿射变换，也可以通过重映射实现动态图像）

图像的灰度变换.py：图像的反色处理（直接用数学方法255-img，和LUT查表计算方法），直方图正规化cv.normalize的使用

图像的直方图处理.py：灰度图与彩色图的直方图展示，灰度图的直方图均衡化（全局），灰度图的限制对比度自适应局部直方图均衡化

图像的阈值处理.py：
固定阈值法，使用固定阈值对灰度图进行前景背景分类；全局阈值法，找到一个适合全局灰度值的固定阈值，对前景背景分类；OSTU阈值算法，使用最大化类间方差找到一个最优阈值T，进行阈值分割；多阈值处理会基于OSTU算法找到多个类间方差进行阈值分割；自适应阈值处理是局部阈值处理，基于像素邻域的内容平均值或高斯加权计算邻域的阈值，抗干扰性强；移动平均阈值处理，和自适应阈值相比，只使用固定的邻域大小和平均值计算邻域阈值，抗干扰能力弱，但是可以基于Numpy数组运算，速度快

图像卷积与空间滤波1.py：基本的图像卷积运算与相关运算，均值滤波和高斯滤波，统计排序滤波器（中值、最大最小值、中点以及修正阿尔法滤波器），自适应局部降噪滤波器，自适应中值滤波器，双边滤波器，图像锐化（钝化掩蔽）

图像卷积与空间滤波2.py：拉普拉斯算子用于图像的边缘检测，sobel算子和scharr算子用于图像的边缘检测，图像金字塔（高斯金字塔降采样上采样，拉普拉斯金字塔弥补高斯金字塔采样过程中的信息丢失）

傅里叶变换和频域滤波1.py：傅里叶变换是将空间区域的灰度值表达形式的图像转换为频域区域的频率信号表达形式的图像，通过频率的形式对图像进行增强和降噪等处理。opencv和numpy方法实现傅里叶变换fft和逆傅里叶变换ifft，opencv实现快速傅里叶变换方法，计算最优傅里叶输入图像尺寸，对图像进行扩充，输入傅里叶变换函数，利用索引对结果图像进行裁剪，速度较快。原傅里叶变换方法时间复杂度O(N^2)，快速傅里叶变换方法时间复杂度O(NlogN)。

傅里叶变换和频域滤波2.py：频域图像滤波的基本步骤（图像——傅里叶变换——低频中心化——频域图像与滤波器双通道进行简单乘法的频域滤波——去中心化——傅里叶逆变换——图像重建——归一化转化图像格式），理想低通滤波器，理想高通滤波器，高斯低通滤波器，高斯高通滤波器，巴特沃斯低通滤波器，巴特沃斯高通滤波器，拉普拉斯高通滤波器（实现边缘检测）。低通滤波器实现降噪和图像模糊平滑，高通滤波器实现图像锐化。
